# ORTUS brand

`src/components/branding/ortusBrand.test.ts` asserts the brand guardrail sentences in README and the codex docs; keep those documents aligned when brand rules change.

- The sharp ORTUS mark is the primary navigation brand. Pair it with the visible ORTUS wordmark in primary navigation, including the mobile lockup.
- Use the soft mark only for secondary presentation states.
- Never use the mark as a world, graph, or Builder watermark. ORTUS workspaces get no separate logos.
- Use source brand assets as supplied: no stretching, distortion, or destructive recoloring.
- Keep the current favicon until small-size legibility of a replacement is confirmed.
- Branding stays isolated from simulation runtime state, and never obscures the current model, scenario, workspace, or runtime state.
- Branding work stays branding work; broad audit recommendations belong to their own milestone.
